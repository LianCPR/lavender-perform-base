# assets/icons

Reserved for app icons, splash art and the exported brand mark.

Phase 01 uses the `BrandMark` component (gradient square + Ionicons glyph) and
Expo's default app icon so the repository contains no binary assets yet. Before
distribution, add `icon.png` / `adaptive-icon.png` / `splash-icon.png` here and
reference them from `apps/*/app.json`.
